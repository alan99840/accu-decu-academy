資料口徑與更新流程

Excel 每個有成交日期與 ISIN 的起始列視為一筆成交；後續 Fixing Date 與 Maturity Date 歸屬該筆商品。相同 ISIN 不會自動合併，同一商品可有不同客戶成交。

年度、季度、月度統計按 Trade Date；認購金額 K＝1,000、M＝1,000,000。資料來源只有所匯入工作簿，不代表完整歷史成交量。

Excel 混用小數與百分數：大於 2 的有效比例除以 100，999 依使用者確認代表無 KO。最終 KO 條款、期初價調整、觀察方式及日期須填入補充 Excel 核對；未核對時不輸出「沒有 KO」。

每日、離散觀察、記憶 KO 與每日記憶 KO 分開計算；缺少任一觀察日價格就顯示待補資料。香港、日本及未辨識標的暫不使用美股行情。跨幣別金額不折算。

更新流程：提供 Termsheet 與成交資料 → 更新原始 Excel 及補充條款表 → 執行同步與加密 → 更新 GitHub 加密資料 → 網頁重新解鎖。原始 XLSB、客戶代碼與解鎖密碼不以明文放上 GitHub。
