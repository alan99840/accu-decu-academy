# SN 監控看板

繁體中文的結構型票據成交、觀察日與到期看板。程式採 MIT 授權，真實交易資料以 AES-256-GCM 加密後才發布。

部署在既有 `alan99840/accu-decu-academy` 倉庫：

- `SN/`：商品工作台。
- `SN/monitor/`：SN 監控看板。
- `SN/accu-decu/`：Accu/Decu 入門簡報。
- `SN/scripts/`、`SN/tests/`：同步、加密、檢查與驗證工具。

## 資料與統計

來源 Excel 以空白列分隔商品區塊；有成交日與 ISIN 的列是一筆成交，區塊的 Fixing Date、Maturity Date 歸屬該商品。成交資訊在區塊末列的情況也一併處理。同 ISIN 的不同客戶不合併；重複列另行提示。統計按實際 Trade Date，按 USD、CNH、JPY 分開顯示，不將不同幣別直接加總。K、M 金額分別乘 1,000、1,000,000。缺失金額保留為未填，不當成零筆成交。

帳戶統計依使用者確認按客戶代碼分組，可看成交筆數、認購金額、Excel 標記在期部位、產品分類、KO 預警及最近觀察／到期事項。按年度與幣別篩選，帳戶加總與總計可勾稽。使用下拉選單選擇單一帳戶，顯示歷史成交範圍、存續與結束部位、產品及發行商分布、監控事項，並以可展開的成交卡片閱讀逐筆條款；其他區塊一起篩選。

KO 的 999 依使用者確認代表無 KO。現有商品以非記憶方式整理；補充表提供離散全數、每日全數、記憶 KO、每日記憶 KO。每日類型需要交易日曆。達到／超過、期初價及公司行動調整、觀察日與條款來源核對後，才能顯示正式條件檢查。未核對時只顯示「表列 KO 價格達標，條款待核對」；不能視為發行商已確認提前贖回。

富途未復權美股日線僅作預警，排除盤前與盤後。行情均標示美國交易日。香港、日本及未辨識市場另行提示。不得用復權行情回算合約初始價，不得用非交易日的最近價補造定盤。每日檢查回看所有需要的觀察日，缺價不輸出健康結論。

## 工作流程

1. 提供最終 Termsheet、成交日、客戶代碼、認購金額和發行商成交確認。
2. 在原始 Excel 新增／更新成交；核對期初價、幣別、票息、KO／KI、到期日與完整觀察日。若新成交尚未列入原始 XLSB，在本機補充 Excel 的「補充成交」與「補充標的」輸入基本成交及標的資料。
3. 在本機補充 Excel 填寫「條款確認」及「觀察日」，包括 KO 模式、是否有 KO、比較方式、條款來源、期初價與觀察日核對狀態。原始 XLSB 保留，同步程式只讀它。
4. 同步原始 Excel＋補充 Excel，更新本機 `private/dataset.json`。來源 XLSB 後續如已新增同一筆補充成交，先移除補充成交列及關聯輸入，避免重複。重排原始列仍按 ISIN＋客戶＋成交日識別；完全相同成交重複時需人工核對。
5. 執行檢查並加密，只更新 GitHub 的 `SN/monitor/data.enc.json`。網頁重新載入／解鎖即讀取最新版。

本機專案把工具放在 `scripts/`、頁面放在 `SN/monitor/`；從 GitHub 下載後亦支援直接在 `SN/` 目錄執行工具（頁面為 `monitor/`）。所有本機明文放在工具根目錄的 `private/`，不可發布。

```sh
python3 -m pip install -r requirements.txt
python3 scripts/sync.py '/path/to/在期SN商品記錄 (自動儲存).xlsb' --supplement '/path/to/SN_監控補充資料.xlsx' --prices private/prices.json
node scripts/check.mjs
python3 scripts/encrypt.py
node tests/model.test.mjs
```

`build_supplement.mjs` 僅用於初次產生補充工作簿，後續不得重建覆蓋已填條款。使用 Artifact Tool 執行，另需其工作區套件。未提供行情檔時，條款及統計仍可展示，KO 價格檢查會提示缺漏。

香港工作日（週一至週五、公眾假期除外）09:15 的收盤檢查由附在本聊天的本機排程讀取 Excel，取得已完成交易日的富途未復權行情，檢查後發布加密資料。排程需要電腦、Codex 及富途連接可用；GitHub Pages 本身不讀取本機 Excel。例行成功更新不發通知，只在新的 KO 預警、到期事件、資料異常或失敗時提醒。先查[香港政府 1823 假期日曆](https://www.1823.gov.hk/tc/hong-kong-public-holidays-ical)，假期跳過，下一個工作日回看並補查所有尚未檢查的美股交易日與觀察日。假期日曆超出涵蓋年份或快取過期會提示異常。可以改用發行商／Bloomberg 資料匯入補充表的「收盤價」，已人工核對的值優先於自動行情。

## 存取與保密

GitHub Pages 的 HTML 和程式碼公開，搜尋引擎 `noindex` 只是減少索引，並非存取控制。真實資料為 AES-256-GCM 密文，解鎖密碼預設以隨機 256 位元產生，亦可由管理者指定至少 8 個字元的密碼；公開密文可被離線嘗試解密，密碼強度會影響保護程度。使用 PBKDF2-SHA256 600,000 次推導金鑰，每次使用新 salt 與 IV。資料先 gzip 壓縮，再加密。密碼只保留在本機 `private/解鎖密碼.txt`，不放在網址、程式碼、GitHub Secret 或瀏覽器儲存。資料僅在記憶體中解鎖，鎖定／重新整理清除。

分享密碼會讓接收者讀取並另存資料。密碼外洩時需要更換並重新加密，歷史密文可能仍存在 Git 歷史，不能以更換新檔案撤回既有副本。公開網站管理員或篡改程式的人仍可能影響未來解鎖安全，故需保護 GitHub 帳戶。這是共享密碼方案，非逐人登入與撤權。

原始 Excel、Termsheet、客戶代碼和密碼的明文不屬於開源授權內容，禁止放入公開倉庫。`private/`、`outputs/`、工作簿與套件目錄已排除。`demo.json` 全部為虛構示範。

## 驗證

核心驗證涵蓋幣別及季度歸屬、等值比較、記憶規則、每日日曆、缺價、無 KO、未確認條款、非美股及已結束狀態。另有加密互通與防竄改驗證，以及桌面／手機、搜尋、篩選、詳情和鎖定檢查。使用各筆來源位置回查 Excel；預警最終須由發行商確認。
