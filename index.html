01
THE BASIC IDEA

先记住两句话

ACCUAccumulator

按约定价格，持续买股。

签约时，执行价通常低于当时的股价。代价是：价格对你不利时，你仍要买，可能还要买更多。

客户支付价款→取得股票
DECUDecumulator

按约定价格，持续卖股。

签约时，执行价通常高于当时的股价。代价是：股票涨得更高，你仍要卖，可能还要卖更多。

客户交付股票→取得价款
老师提醒

这是带有条件的买卖义务。报价中的“折价买入”或“溢价卖出”，是相对签约时的股价而言；未来的市场价可能比你的买价更低，或比你的卖价更高。普通 Accu / Decu 也不能直接理解为“本金加票息”。[1]

为什么银行愿意给一个看起来更好的价格？

你取得更有利的执行价，同时承担某些不利情境下的履约义务。一个简化的期权理解是：Accu 接近一系列买入看涨、卖出看跌的组合；Decu 则接近买入看跌、卖出看涨。数量倍数、障碍价与保证期会进一步改变收益结构。

价格优势来自风险交换。不能只看“比今天便宜 10%”，还要看你最不愿意买／卖的时候，需要履行多大义务。

04
BARRIERS & GUARANTEED PERIOD

KO、KI、保证期：分别改变什么？

KO

Knock-out / 敲出

结束合同规定的后续部分。典型 Accu 在上涨时 KO，典型 Decu 在下跌时 KO。它通常在有利方向触发，不能当作不利方向的止损线。

此前已经累计的买卖义务，通常仍须履行；Accu 已取得的股票继续随市价涨跌。

KI

Knock-in / 敲入

激活条款指定的规则。可能是开始承担义务、启动倍数，或改变另一项条件。只有合同明确列明，才有 KI。

每日跌破／涨过执行价就加倍，可以只是当天的数量规则，不必然是 KI。

GP

Guaranteed period / 保证期

保证某段期间或某个数量的义务。有些结构提早 KO 后，仍要完成最低买卖数量。另有结构在最初一段期间不观察 KO。

保证的是义务或数量，不是盈利，也不是本金。

先读观察规则

KO 价是 105：某天盘中到过 106，收盘却是 103。如果按盘中连续观察，可能已经 KO；如果只看每日收盘，可能没有 KO。还要核对“达到”还是“超过”、KO 当日计不计量，以及保证期如何处理。[2]

“当天 2x”与“敲入后一直 2x”，结果不同

股价 100→跌到 75→回到 100
假设 Accu 规则第一天第二天第三天
每日判断：低于 K=90 就 2x100 股200 股100 股
假设 KI=80：敲入后永久 2x100 股200 股200 股

第二行仅用于解释“触发后锁定”的概念，并非所有 Accu 的通用条款。观察方式也可分为连续／每日观察或到期观察；“美式／欧式”在这里描述观察方式，不是市场所在地。[4]

保证期碰上 KO，会发生什么？

假设合同明确保证前 20 天每天 100 股，即使第 3 天 KO，仍可能要完成这段期间规定的最低数量。至于是继续每天累计，还是 KO 时一次补足，补足部分用 1x 还是 2x，须看具体公式。

“有保证数量”与“最初不观察 KO”是不同设计。不要把两者混为一谈。

报价里还可能出现哪些变体？

1x 或无 KO：可以不加倍，或没有价格敲出。分段执行价／障碍价：价格可能随时间调整。目标敲出：可能按累计数量、约定收益或其他目标终止，其计量公式及最后一期处理需单独核对。

多标的或篮子：观察哪只股票、怎样确定数量、交付哪只股票，可能按不同规则处理。还可能附带特定 KI、数量上限或提前终止条件。每一项都会改变现金流，不能从 Accumulator / Decumulator 的名称直接推断。

一个常见的教学口径 / 每个观察日定价

Accu 客户差额q × (S − K)Decu 客户差额q × (K − S)

正数表示客户收款，负数表示客户付款。多日金额按合同汇总；参考价 S 可能是观察日价、批次结算价或其他指定价格。
实物交割后，股息和公司行动如何处理？

尚未取得股票时，通常不会仅因累计义务就拥有股东权利。交割后的股息资格要看除息日、登记日等规则；合约也可能对股息作特别调整。

拆股、合并、收购、停牌或退市等事件，可能触发数量／价格调整、替代标的或提前终止。具体由合同和计算代理条款决定。[3]

保证金，不是最大亏损

数量加倍和保证金融资是两种不同的放大机制。计算风险时，先算最大可能的买卖义务，再看如何筹措资金。

假设初始保证金 30%：54,000 港元

这并不把购股义务或亏损限制在 54,000。如果 2,000 股全部按 90 买入，最后股票跌到 0，股票损失可达 180,000 港元，尚未计融资和费用。保证金比例在此仅是算术假设，并非实际报价。

ACCU / 资金侧

股价下跌可能带来双重压力

  • 当天买股数量增加，购股现金需求上升。
  • 合约市值变差，可能同时被要求追加抵押品。
  • 交割价款与保证金如何抵扣，要看资金安排；不能自动视为可互换，也不能简单重复相加。
DECU / 股票侧

备兑和不足额交付，风险不同

  • 备兑：持有足够股票，可按约交付；仍可能有未售股票的下跌风险和低于市场价卖出的机会成本。
  • 股票不足：可能要高价购股，再按低执行价交付。若无其他保护，股价上涨带来的补购损失理论上没有上限。
实际盈亏 ≠ 机会成本

原来以 80 买入股票，按 Decu 的 110 卖出，原持股每股赚 30；如果当时市场价是 130，相对市场价每股少收 20。模拟器的 Decu“相对期末卖股的差额”衡量后者，不能当作原持仓利润。

提前平仓为什么不只看已累计的亏损？

提前终止通常要按剩余合约的市值结算，可能另有价差、手续费或流动性成本。估值还受剩余期限、波动率、利率、股息及信用等因素影响。不能用“已经买了多少股 × 今天价差”代替整个合约的平仓报价。[2]

此外要核对交易币种、股票币种与资金币种是否一致；货币转换、税费和融资成本可能改变最终结果。

PAYOFF ≠ LEGAL FORM ≠ TRADING VENUE

Note 与 OTC，先分清比较的是哪一层

Accu / Decu 描述收益和义务结构；Note 描述证券／债务工具形式；OTC 描述场外交易。一只 Note 也可以在场外发行或交易，所以“Note 和 OTC”不是严格互斥的分类。

03 / 交易与交割场外／场内 · 现金／股票

实务中真正想比较的：全额缴款 Note 与双边 OTC 衍生品

比较维度通常的全额缴款 Note双边 OTC Accu / Decu 合约
法律关系投资者持有发行人发行的证券，通常是发行人的债务义务客户与交易对手订立衍生品合同，各自承担约定义务
开始时资金通常缴付认购本金可能缴付保证金、提供抵押品，或采用其他资金安排
后续追加义务普通全额缴款且无追加义务的 Note，通常没有产品内的追缴保证金；外部融资另计可能有追加抵押品、购股现金或交股要求
结算按发行条款：可能现金兑付、股票交付或特定组合按确认书：可能实物交割或现金差额
文件发行文件、最终条款、认购／托管安排主协议、交易确认书、抵押品／保证金文件
提前退出看有没有二级市场或发行人回购；可能有折价和流动性限制看能否平仓；按剩余合约市值及合同约定成本处理
信用风险承担发行人及适用保证人的信用风险；很多结构性 Note 为无担保债务承担交易对手风险；抵押、净额结算等安排会影响风险
看到“Accumulator Note”怎么办？

先确认本金如何使用、会否分批交股票、未用资金如何处理、到期如何兑付，以及客户还有没有追加付款义务。名称不能证明它和普通 OTC Accu 有同样现金流。全额缴款也不代表保本。[5]

DESK REFERENCE

术语速查

Underlying / 标的

决定产品结果的股票或其他资产。

Initial price / 期初价

签约时的参考价，不是保证未来能买卖的市场价。

Strike / Forward price

按约履行买卖义务的执行价 K。

Daily quantity / 基础股数

每个观察日正常情境下的数量。

Gearing / 数量倍数

特定情境把基础数量放大，例如 2x。

Fixing / Observation

用于决定当次数量或触发事件的观察。

KO / Knock-out

触发后结束条款指定的后续部分。

KI / Knock-in

触发后激活条款指定的规则。

Guaranteed period

约定的最低履约期间／数量，不保证收益。

Settlement / 结算

按约交换股票与现金，或收付净差额。

Margin / 保证金

担保履约的抵押安排，不是最大亏损。

MTM / Mark-to-market

当前合约估值，包含未来义务的价值。
